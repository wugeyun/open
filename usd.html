USD Price API

免费的实时美元行情 API，支持 BTC 和 XAU（黄金现货）。无需注册、无需 Key、CORS 全开。

接口

GET/api/usd — 返回当前价格（JSON）
GET/api/usd?symbols=btc,xau — 指定品种（可选值：btc, xau，逗号分隔）
GET/usd.html?format=json — 本页面的纯 JSON 视图（同 API 内容）

响应字段

字段类型说明
symbolstring品种代码（如 BTC/USDT）
pricenumber | null美元价格；所有数据源失败时为 null
sourcestring | null实际命中的数据源
updatedAtstringISO 8601 时间戳
errorstring | null错误信息；成功时为 null
